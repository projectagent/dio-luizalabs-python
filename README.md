## 📌 Sobre

Este repositório armazena os **códigos, exercícios e projetos práticos** desenvolvidos durante o **Bootcamp da LuizaLabs focado em Python**, oferecido pela plataforma [Digital Innovation One (DIO)](https://www.dio.me/).

O objetivo principal é **registrar a evolução no aprendizado** da linguagem Python e **documentar a resolução dos desafios** propostos ao longo do curso.

---

## 🚀 Como Executar

### Pré-requisitos
- [Python 3.x](https://www.python.org/downloads/) instalado

### Rodando um script
```bash
# Exemplo: executar o arquivo de tipos de dados
python "Primeiros Passos e Versionamento de Código/Conhecendo a Linguagem/tipos_de_dados.py"
```
